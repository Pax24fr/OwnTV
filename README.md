# OwnTrakt

Version personnalisée de [OwnTV](https://github.com/ahXN00/OwnTV) avec intégration Trakt et diverses améliorations ergonomiques pour Android TV.

> Cette version peut être installée en parallèle de l’application officielle OwnTV (nom affiché : **OwnTrakt**).

## Téléchargement

- **Dernière version (APK)** : [Télécharger la release](https://github.com/Pax24fr/OwnTV/releases/latest)

## Migration depuis OwnTV

Tu peux récupérer très simplement ta sauvegarde OwnTV et la réappliquer sur OwnTrakt pour retrouver immédiatement toutes tes préférences, playlists, favoris, etc.

## Principales modifications

### Intégration Trakt.tv
- Ajout de Trakt (marquer comme vu via menu + interception de la fin de visionnage)

### Améliorations ergonomiques (QoL / UX TV)
- **Fermeture instantanée du Rail de Navigation** : cliquer OK sur un élément du menu sélectionne la section et focalise immédiatement le contenu.
- **Bouton Back pour effacer la recherche** : sur les chaînes Live TV, Films et Séries, un appui sur Back vide instantanément la recherche active.
- **Personnalisation des flèches Haut/Bas du lecteur Live** : réglage dans *Settings › Remote shortcuts › Player buttons* (Zapper / Contrôles & Historique / Désactivé).
- **Menu rapide sur les affiches Now Trending** : menu contextuel (Détails, Bande-annonce, Favoris, Télécharger) sur les posters de l’accueil.
- **Ordre des actions du menu Playlist** : Re-sync placé en premier dans *Settings › Playlists*.
- **Onglet Téléchargements** : l’onglet Recordings est mis en premier.
- **Raccourci télécommande « Toggle favorite »** : action configurable pour basculer le statut favori du contenu actif (avec notification).
- **Indicateurs de playlist unifiés** : badges de playlist cohérents + point coloré sous les affiches en mode grille VOD.
- **Focus Mini-player depuis le Guide TV** : second appui OK sur une chaîne focalise directement les contrôles du mini-player ; BACK remet le focus sur la ligne du guide.
- **Encodage EPG** : correction pour forcer la lecture UTF-8 des guides XMLTV.

## Installation

1. Télécharge l’APK depuis les [Releases](https://github.com/Pax24fr/OwnTV/releases)
2. Autorise l’installation d’applications inconnues sur ta TV / box Android
3. Installe l’APK
